# DnD Club Party Prep

**Live site:** https://secretpizza14.github.io/dnd-club-party-prep/

A one-page party planner for the DnD club: checklist, notes, guest list, and comments on everything.
Red, white, and green with pixel headings, falling snow, and public-domain Christmas carols synthesized live in the browser.

## What's inside

- **Party checklist** — add items, check them off, add notes to each item
- **Comments everywhere** — on items, on notes, and on the party itself
- **Guest list** — RSVP status (Going / Maybe / Can't come) and a live headcount
- **Send link** — native share sheet or copy-to-clipboard
- **Secret text color menu** — type `colcolcol` to open it
- Everything saves in `localStorage`, so each visitor keeps their own copy of the list

## Music

*Jingle Bells* (1857), *Deck the Halls* (1862), and *We Wish You a Merry Christmas* (traditional).
No audio files — the melodies are generated with the Web Audio API, so there are no recordings and nothing to license.

## Run it

Open `index.html` in a browser. No build step, no dependencies, no network requests.
